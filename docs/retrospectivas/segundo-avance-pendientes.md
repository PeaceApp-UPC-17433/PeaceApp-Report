# Registro de ceremonias pendiente de evidencia

Estado al 30 de octubre de 2026: no se dispone de acta, grabación o registro de asistencia verificable de Pair Programming, Sprint Review o Sprint Retrospective. Este archivo es una guía para completar el registro, no un acta de una sesión realizada.

## Pair Programming

Consignar fecha y duración reales, participantes, roles Driver/Navigator, cambios de roles, objetivo, problema resuelto, commits o PR y resultados de pruebas.

## Sprint Review

Consignar sprint, fecha, participantes, objetivo del incremento, revisión del código demostrado, entorno, criterios de aceptación demostrados, observaciones de stakeholders, decisión de aceptación y ajustes al backlog. La comprobación técnica disponible se encuentra en docs/segundo-avance/evidencias/.

## Sprint Retrospective

Consignar fecha, participantes, observaciones del proceso, acciones acordadas con responsable y plazo, y evidencia de seguimiento. Las oportunidades detectadas en la auditoría técnica no deben atribuirse a acuerdos del equipo sin validación.
